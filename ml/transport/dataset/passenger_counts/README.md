# Kaggle Public Transportation Passenger Counts Dataset

## Source Information
- **Dataset Title**: Public Transportation Passenger Counts
- **URL**: [https://www.kaggle.com/datasets/ifuurh/public-transportation-passenger-counts](https://www.kaggle.com/datasets/ifuurh/public-transportation-passenger-counts)
- **Author**: Oliver Hennhöfer

## Download Instructions
Since Kaggle requires account authentication and API keys to download directly, please follow these steps to download manually if you wish to use this dataset:

1. Open [https://www.kaggle.com/datasets/ifuurh/public-transportation-passenger-counts](https://www.kaggle.com/datasets/ifuurh/public-transportation-passenger-counts) in your browser.
2. Log in to your Kaggle account.
3. Click on the **Download** button in the top right.
4. Extract the downloaded archive and place the CSV file inside this directory:
   `ml/transport/dataset/passenger_counts/`
